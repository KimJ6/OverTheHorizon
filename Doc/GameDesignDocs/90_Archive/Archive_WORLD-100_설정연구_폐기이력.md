# 2. 세피로트·세피라 모티프 검토

## 2.1 별도 세피라 종족안

과거에는 세피라를 다음과 같은 별도 존재로 설정하는 안을 검토했다.

- 인간과 다른 제3의 존재
- 복수세계 인과를 관계시키며 자기동일성을 유지하는 존재
- 인간+리마니움 메카가 근사하는 존재

그러나 심향물리계 자체가 이미 다세계 공통축을 설명하기 때문에 별도의 고차 존재를 추가하면 근본 원리를 중복 설명한다는 문제가 있었다.

현재 Canon에서는 **세피라를 독립 종족으로 확정하지 않는다.**

## 2.2 세피로트적 관계구조

현재까지 유효하게 남은 것은 종족이 아니라 구조적 모티프다.

- 여러 세계의 인과를 구별한다.
- 구별된 상태로 관계시킨다.
- 완전 융합이 아니라 경계가 유지된다.

이 모티프는 WORLD-100에서 심향물리계의 정상 관계구조를 설명하는 작가측 참고로만 남긴다.

## 2.3 Tzimtzum / Tohu / Shevirah / Qlippah / Tikkun

과거 검토에서 사용한 구조적 대응은 다음과 같다.

- **Tzimtzum**: 개별 존재와 세계가 성립하기 위한 경계·제한
- **Tohu**: 각각은 정합적이지만 서로의 과거를 포함하지 못하는 독립된 질서
- **Shevirah**: 세계간 귀속구조 붕괴 또는 개체 수준의 구조붕괴
- **Qlippah**: 통합적 자기연속성을 잃고 껍질처럼 기능과 형태만 남는 상태
- **Tikkun**: 과거를 되돌리는 것이 아니라 남은 것을 새로운 관계에 재배치하는 행위

이들은 세계 내부의 객관적 물리용어라기보다 창작 설계 모티프다.

# 3. 에반게리온 비교에서 남긴 것과 배제한 것

## 3.1 참고한 구조

참고 가치가 있다고 판단한 것은 다음 정도다.

- 깊은 관계와 동조가 필요해도 완전한 융합은 위험할 수 있다.
- 경계는 관계를 방해하는 것이 아니라 개체성을 유지하는 조건일 수 있다.
- 더 높은 동조가 항상 더 좋은 것은 아니다.

현재 기획에서는 이를 다음 방향으로 변형했다.

> **융합보다 관계.**

> **경계가 있는 존재들이 관계할 때 선택 주체가 유지된다.**

## 3.2 직접 채택하지 않는 것

- 인간과 메카의 생물학적 융합
- 메카 내부의 인간 영혼
- 동조율이 곧 파워레벨이 되는 구조
- 인간+메카의 신적 존재 진화
- 자아경계 붕괴를 이상상태로 취급하는 구조

---

# 4. 카운터사이드 비교에서 남긴 것과 배제한 것

## 4.1 참고한 구조

가장 중요한 참고점은 명칭이 아니라 **설정 층위를 분리하는 방식**과, 한 세계의 역사가 특정 존재에 집중되어 그 존재가 세계의 결과를 대표하게 되는 모티프였다.

이 검토에서 현재 Canon의 `인과수렴` 개념이 발전했다.

## 4.2 직접 채택하지 않는 것

- 세계의 의지
- 세계가 특정 영웅을 선택하는 구조
- 대적자 선정
- 세피라의 수호자 직접 대응
- 세계의 하드리셋 장치
- 세계가 자동으로 소환하는 면역체계

현재 Canon에서는 세계 자체에 자아나 의지를 부여하지 않는다.

---

# 5. 인과수렴체 검토 이력

과거의 `선택받은 자`, `세피라적 존재`, `세계 대표자` 아이디어는 현재 다음과 같이 변형되었다.

> 세계가 선택한 것이 아니라, 수많은 실제 사건과 선택이 결과적으로 한 존재에 거대한 인과관성을 집중시킨다.

이 존재가 원세계 폐색 뒤에도 이성적인 행위주체로 남을 수 있는 메커니즘은 아직 미정이다.

해당 미정 문제는 WORLD-100의 `Open Canon`에서 관리한다.

---

# 6. Tikkun과 Gameplay 루프에 대한 해석

과거 문서에서는 다음 Gameplay 흐름을 Tikkun 모티프와 연결했다.

```text
폐색체 파괴
→ 리마니움 회수
→ 가공
→ 기체 수복·강화
→ 새로운 전투와 선택
```

중요한 해석은 원상복구가 아니라:

> **이미 일어난 과거를 인정한 상태에서 남은 것을 새로운 관계 속에 두어 다음 미래를 만든다.**

는 방향이다.

이 모티프는 현재 프로젝트의 철학적 해석으로 참고할 수 있으나, Gameplay 규칙 자체의 Owner는 `SYS-140`과 `SYS-160`이다.

# 8. 폐기된 과거 해석

다음은 현재 Canon이 아니다.

- 인과폐색 = 가능성이 줄어 하나의 미래만 남는 현상
- 완전폐색 = 모든 다른 인과연결이 사라져 하나의 경로가 고정되는 현상
- 리마니움 = 여러 세계의 실제 과거가 금속에 동시에 저장된 것
- 리마니움 = 폐색된 인간이 잃은 가능성의 물질화
- 리마니움 = 마음 없는 적이 다른 사람의 가능성을 축적한 것
- 세계의 의지라는 별도 초월력
- 세피라 = 세계의 신성 또는 인과관성
- 세피라 = 반드시 인간과 다른 제3 종족
- 인간+메카 = 세피라 종족으로 진화 또는 융합

# 9. 보류된 과거 해석

현재도 결정되지 않은 항목은 Archive에서 결론 내리지 않는다.

- `신성`이라는 명칭 자체
- 세피라/세피로트를 실제 세계 내 학술용어로 사용할지
- 세계 규모 완전폐색을 `클리파`라고 명명할지
- 인과수렴체의 개체수준 다중인과 정합 능력의 발생원인
- 인과적 거리의 수학적·Gameplay 표현

이 항목들의 현행 상태는 WORLD-100의 `Open Canon`이 우선한다.
