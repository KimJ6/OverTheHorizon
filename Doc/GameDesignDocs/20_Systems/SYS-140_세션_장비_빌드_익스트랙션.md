# SYS-140 세션·장비·빌드·익스트랙션 시스템

> **플레이어는 기본 장비로 출격해 회수 장비와 소모품을 획득하고, 소모품 계열에 세션 한정 빌드 강화를 축적하며 더 깊이 진입할지 복귀할지를 판단한다. 복귀하면 회수품과 운용 데이터를 보존하고, 실패하면 세션 획득물을 잃으며 기존 장비도 손상된다. 반복 회수와 운용 데이터는 제한적 영구 보상인 열화판 해금으로 이어진다.**

## 0. 문서 계약

### 0.1 이 문서가 결정하는 것

본 문서는 한 번의 출격에서 무엇을 가지고 시작하고 무엇을 획득·사용·강화하며, 무엇을 잃거나 보존한 채 끝내는지 정의한다. 세션 상태, 장비·소모품·빌드, 내구도·수리, 복귀 결과와 정산, 잔해·운용 데이터·열화판, 관련 밸런스와 검증 기준을 소유한다.

### 0.2 이 문서가 결정하지 않는 것

프로젝트 목표는 [PRJ-000](../00_Project/PRJ-000_프로젝트_통합기획_기준서.md), 공통 전투 Runtime은 [ARCH-100](../10_Architecture/ARCH-100_전투_적성객체_아키텍처.md)이 소유한다. 기동은 [SYS-110](SYS-110_플레이어_기동.md), 자동 Targeting·직사 판정은 [SYS-120](SYS-120_자동타게팅_직사화기.md), Missile 행동은 [SYS-130](SYS-130_미사일_이타노서커스.md), 파밍 노드·안전권·전선·분견대는 [SYS-160](SYS-160_군도작전_전방지원.md), 회수·제식화의 설정적 이유는 [WORLD-100](../30_World/WORLD-100_세계관_Canon.md)이 결정한다.

`SYS-160`이 획득 장소와 안전권 도달을 판정하면, 본 문서는 획득물의 세션 상태와 가치, 복귀 성공·실패와 정산 결과를 확정한다.

### 0.3 현재 범위

숫자·슬롯 수·성능 비율·수리량과 복수 후보는 Open Decision으로 유지한다. 장기 성장은 현재 채택 범위인 열화판과 운용 데이터까지만 다루며, 추가 메타 경제를 새로 만들지 않는다.

## 1. 시스템 요약

### 1.1 시스템이 해결하려는 문제

| 문제 | 설계 방향 |
|---|---|
| 로그라이트 강화가 장비 교체 때문에 무효화되는 문제 | 강화 기준을 개별 장비가 아니라 장비가 사용하는 소모품 계열에 연결 |
| 강한 회수 장비를 얻으면 영구 고정될 수 있는 문제 | 내구도·반복 수리 한계·수명 저하로 순환 유도 |
| 익스트랙션 실패가 지나치게 가혹할 수 있는 문제 | 세션 획득물은 잃되 출격 전 장비는 완전 삭제보다 큰 손상 방향을 사용 |
| 장비 파괴가 즉시 세션 빌드 붕괴로 이어지는 문제 | 장비는 파괴되어도 해당 소모품 계열의 빌드 강화는 세션 중 유지 |
| 파워 스파이크가 생겨도 계속 싸울 이유가 없는 문제 | 강한 세션 상태일수록 더 깊이 진입할 유인을 제공하고, 소모품·내구도 저하가 복귀 압박을 만든다 |
| 장기 반복에서 회수 경험이 남지 않는 문제 | 잔해와 운용 데이터를 열화판 해금에 연결 |

### 1.2 핵심 플레이 감정

```text
안정적인 기본 장비로 출격
        ↓
회수 장비 획득 / 교체
        ↓
소모품 계열 빌드 강화
        ↓
전투 효율 상승
        ↓
파워 스파이크
        ↓
더 깊이 진입하고 싶은 욕구
        ↕
소모품 고갈 / 내구도 저하 / 회수품 가치 증가
        ↓
복귀 판단
        ↓
성공: 보존과 다음 세션 준비
실패: 세션 획득물 손실과 기존 장비 손상
```

## 2. 세션 구조

### 2.1 세션 정의

`세션`은 **1회 출격부터 복귀 성공 또는 복귀 실패까지의 플레이 단위**다.

세션 안에서는 다음 상태가 반복된다.

```text
출격
→ 진입
→ 전투
→ 파밍
→ 장비 교체 / 빌드 강화
→ 더 깊이 진입 또는 복귀 판단
→ 복귀 성공 / 실패
→ 정산
```

군도에서 실제 이동하는 경로, 구획 상태, 안전권과 작전 항로는 `SYS-160`이 소유한다.

### 2.2 세션 시작

세션은 아군 함대권 또는 점령 섬의 안전권에서 출격하는 것을 기본 전제로 한다.

세션 시작 시 제공되는 핵심 요소:

- 기본 장비
- 초기 소모품
- 이전 세션에서 보존된 장비가 있다면 해당 장비 구성

본 문서는 출격 위치의 공간적 규칙을 결정하지 않는다.

### 2.3 세션 진행

세션 진행 중 플레이어는 다음 결정을 반복한다.

1. 회수 장비를 현재 장비와 교체할지 판단
2. 획득한 소모품을 사용해 전투를 지속할지 판단
3. 현재 빌드 강화 방향을 선택
4. 장비 내구도와 소모품 잔량을 고려해 심층 진입 여부 판단
5. 회수품의 가치를 고려해 복귀 여부 판단

이 구조에서 `전투 성능 상승`과 `손실 위험 증가`는 동시에 누적되어야 한다.

### 2.4 세션 종료

세션 종료는 다음 두 결과로 구분한다.

#### 복귀 성공

- 회수 장비 보존
- 잔해 보존
- 분석 데이터 보존
- 장비 임시 수리 가능
- 운용 데이터 축적 가능
- 세션 한정 빌드 강화 종료

#### 복귀 실패

- 세션 중 습득한 장비 상실
- 출격 전 장착 장비는 완전 소실보다 큰 내구도 감소 또는 일부 손상 방향
- 세션 한정 빌드 강화 종료
- 반복 실패가 군도 전선·아군 지원에 미치는 영향은 `SYS-160`이 처리

복귀 성공을 판정하는 공간 조건은 `SYS-160`의 안전권 규칙을 따른다.

## 3. 장비 모델

### 3.1 장비 분류

| 분류 | 정의 | 역할 |
|---|---|---|
| 장비 | 세션 중 획득·장착·교체 가능한 전투 수단 | 전투 방식 변화 |
| 기본 장비 | 출격 시 안정적으로 제공되는 장비 | 실패 후 재도전 안전망 |
| 회수 장비 | 전장에서 획득하는 내구도 기반 장비 | 익스트랙션 핵심 보상 |

회수 장비는 강한 성능을 제공할 수 있지만 영구 고정 자산으로 취급하지 않는다. 내구도·수리 한계·장기 열화가 장비 순환을 만든다.

### 3.2 장착 구조

현재 소스에서 제안된 장착 구조는 다음과 같다.

| 장착 위치 | 장착 가능 장비 | 기본 역할 | 상태 |
|---|---|---|---|
| 양손 | 한손 장비 2개 또는 양손 장비 1개 | 주 화력 | 구조 방향 채택 |
| 서브암 | 한손 장비 | 보조 화력 | 2기 구조가 현재 후보 |
| 하드포인트 | 미사일 포드, 로켓, 플레어 등 제한 사용성 장비 | 순간 화력·위기 대응·보스 대응 | 최종 개수 미정 |

#### 장착 위치와 장비 특성은 분리한다

장착 위치가 무기의 공격 방식이나 계산 빈도를 결정하지 않는다.

예:

- 같은 한손 장비를 손에 장착하든 서브암에 장착하든 기본 무기 특성은 동일
- Targeting 계산 주기는 장착 위치가 아니라 장비의 공격 방식·발사 주기 기준
- 서브암은 빌드 강화에 의해 독립 Targeting 특성을 얻을 수 있음

실제 자동 Targeting 규칙은 `SYS-120`을 따른다.

### 3.3 수동 장비 교체

자동 사격을 기본으로 하더라도 플레이어는 상황에 맞는 장비를 수동으로 교체한다.

장비 교체의 목적:

- 거리 변화 대응
- 적 밀집도 대응
- 고도·엄폐 대응
- 소모품 잔량 관리
- 현재 빌드 강화와의 시너지 선택

최종 입력 방식은 `Open Decisions`에서 결정한다.

## 4. 장비 공격 유형

본 문서는 장비가 어떤 Gameplay 공격 범주에 속하는지를 정의한다. Target 선택·사선 판정·Projectile 처리의 상세 구현은 `SYS-120`, `SYS-130`, `ARCH-100`을 따른다.

| 공격 방식 | Gameplay상 유효 영역 | 플레이 의미 |
|---|---|---|
| 히트스캔 | 발사점에서 Target까지 직접 연결되는 직선 | 장애물과 딜각 중요 |
| 직사 투사체 | 탄속을 가진 직선 궤적이 도달 가능한 공간 | 거리와 이동 예측 중요 |
| 곡사 투사체 | 포물선 궤적 또는 착탄 가능 지점 | 엄폐 뒤·고도차 활용 |
| 폭발형 | 착탄점 주변 범위 | 군집 대응과 직접 시야선 의존 완화 |
| 산탄형 | 전방 원뿔·부채꼴 | 근거리 접근과 넓은 각도 활용 |
| 관통형 | 선형 공격 볼륨 | 적 배열과 포지셔닝 활용 |
| 유도형 | Lock-on 또는 추적 가능한 범위 | Target 유지와 발사 타이밍 중요 |
| 설치·장판형 | 특정 지점과 지속 범위 | 경로 제어와 구역 장악 |

### 인터페이스 원칙

- 기본 고속 직사 화기의 Targeting·First-hit → `SYS-120`
- Missile 기반 유도체의 내부 Guidance와 요격 가능 상태 → `SYS-130`
- World Projectile / Instant Resolve 공통 Runtime → `ARCH-100`

본 문서에서는 각 공격 유형의 최종 수치·Target Score·Hit 알고리즘을 정의하지 않는다.

## 5. 장비 소모품

### 5.1 정의

`장비 소모품`은 장비 사용에 필요한 세션 지속 자원이다.

현재 소스의 대표 범주:

- 탄약
- 연료
- 에너지
- 냉각재 등

소모품은 단순 탄약 수치가 아니라 다음 두 구조를 연결한다.

```text
장비 사용 비용
+
세션 지속력
+
빌드 강화 적용 기준
+
복귀 판단
```

### 5.2 획득 위치와 본 문서의 책임

어떤 공간에서 어떤 소모품이 주로 등장하는지는 `SYS-160`이 소유한다.

현재 군도 설계에서는 일반적으로:

- 섬 구획 → 회수 장비 중심
- 함대 잔해 → 소모품 중심

이라는 역할 분리가 사용된다.

본 문서는 획득 후 소모품이 **어떤 장비를 사용할 수 있게 하고 어떤 빌드 강화의 적용 기준이 되는지**를 결정한다.

### 5.3 소모와 복귀 압박

강한 장비를 계속 사용할수록 소모품과 내구도가 감소한다.

따라서 플레이어가 강해진 세션에서도 다음 판단이 유지되어야 한다.

```text
지금의 빌드가 강하다
        ↓
더 깊이 갈 수 있다
        ↓
하지만 소모품과 내구도는 줄어든다
        ↓
현재 회수품을 지킬 것인가
더 큰 보상을 노릴 것인가
```

## 6. 빌드

### 6.1 빌드의 정의

`빌드`는 다음 세 요소가 결합된 **세션 내 전투 방식**이다.

| 요소 | 의미 |
|---|---|
| 장비 구성 | 현재 장착한 장비 조합 |
| 장비 시너지 | 공격 방식·소모품·위치 조건·기동 방식의 조합 효과 |
| 빌드 강화 | 세션 중 선택하는 로그라이트 강화 |

### 6.2 빌드의 목표

빌드는 특정 장비 하나를 오래 보유하는 것보다 **현재 얻은 장비와 소모품 구조에 맞춰 세션의 전투 방식을 바꾸게 하는 것**을 목표로 한다.

빌드 강화가 장비 하나에 귀속되면 장비 파괴·교체 시 강화가 무효화될 수 있으므로, 현재 설계는 소모품 계열을 주요 연결 기준으로 사용한다.

## 7. 소모품 기반 빌드 강화

### 7.1 핵심 규칙

| 규칙 | 현행 방향 | 목적 |
|---|---|---|
| 적용 기준 | 강화는 탄약·연료·에너지 등 소모품 계열에 적용 | 장비 교체에 대한 내성 확보 |
| 장비 파괴 | 장비는 사용 불가가 되지만 해당 소모품 강화는 세션 중 유지 | 성장 단절 방지 |
| 동일 소모품 장비 획득 | 기존 강화 적용 가능 | 동일 장비 반복 파밍 강제 방지 |
| 다른 소모품 장비 획득 | 기존 강화가 그대로 적용되지 않는 방향 | 빌드 선택 의미 유지 |
| 세션 종료 | 빌드 강화 종료 | 로그라이트 세션 구조 유지 |

`다른 소모품 장비`에 기존 강화가 완전히 미적용되는지 일부만 제한 적용되는지는 소스에서 확정되지 않았으므로 `Open Decisions`로 유지한다.

### 7.2 현재 제안된 강화 유형

다음은 소스 문서에 제안된 현재 강화 방향이다. 구체 수치와 최종 종류 수는 아직 확정하지 않는다.

| 유형 | 방향 | 대표 대가/제약 |
|---|---|---|
| 안정화형 | 소모품 소모·내구도 소모 완화 | 순간 화력 상대적 감소 |
| 출력형 | 피해량·사거리·연사 효율 증가 | 소모품 소모 증가 |
| 고위험 출력형 | 큰 성능 상승 | 내구도·소모품 급감 |
| 기동 연동형 | 특정 기동 이후 공격 효율 증가 | 부스트 소모 증가 가능 |
| 서브암 Targeting형 | 서브암에 독립 Targeting 성격 부여 | 특정 상황 의존성 증가 |

기동 조건의 실제 판정은 `SYS-110`, 독립 Targeting 동작은 `SYS-120`을 따른다.

### 7.3 장비 파괴와 빌드 지속

장비가 세션 중 파괴되더라도 세션에서 획득한 빌드 강화 자체는 즉시 사라지지 않는다.

```text
장비 파괴
→ 해당 장비 사용 불가
→ 소모품 계열 빌드 강화는 유지
→ 동일 계열 장비를 다시 획득하면 강화 활용 가능
```

이 규칙은 장비 손실과 세션 성장의 완전한 동시 붕괴를 방지한다.

## 8. 장비 생애주기

### 8.1 전체 Lifecycle

```text
습득
→ 장착 여부 판단
→ 사용
→ 빌드 강화 적용
→ 내구도 감소
→ 파괴 또는 복귀
→ 복귀 시 임시 수리
→ 반복 운용
→ 최대 수명 저하
→ 잔해·운용 데이터 축적
→ 열화판 해금
```

### 8.2 습득

플레이어는 세션 중 회수 장비·잔해·소모품을 획득한다.

장비가 실제로 어느 전장 노드에서 등장하는지는 `SYS-160`이 결정한다.

### 8.3 장착 판단

획득 장비는 현재 장비와 비교하여 즉시 장착·교체하거나 보존 대상으로 둘 수 있다.

세부 Inventory 용량, 현장 보관 UI, 물리적 수납 방식은 현재 소스에서 확정되지 않았다.

### 8.4 사용과 내구도 감소

장비는 다음 요인으로 내구도가 감소할 수 있다.

- 장비 사용
- 피격
- 과출력

정확한 감소량과 장비 유형별 내구도 모델은 미정이다.

### 8.5 장비 파괴

내구도가 부족해진 장비는 해당 세션에서 사용할 수 없게 된다.

장비 파괴는 해당 장비의 사용 불능을 의미하지만, §7의 소모품 기반 빌드 강화는 세션 동안 유지된다.

### 8.6 복귀와 보존

복귀 성공 시 회수 장비는 보존될 수 있으며, 이후 임시 수리를 통해 다시 사용할 수 있다.

### 8.7 임시 수리와 반복 운용

소스 문서는 복귀 후 장비의 내구도와 사용량을 일부 회복시키는 `임시 수리`를 사용한다.

다만 반복 수리를 통해 장비를 무기한 유지하지 않는다.

현재 방향:

- 수리 후 재사용 가능
- 반복 운용 가능
- 반복 수리·운용 시 최대 내구도 또는 안정성이 점진적으로 저하
- 강한 원본 장비의 영구 고정 방지

수리량과 최대 수명 저하 공식은 `Open Decisions`다.

## 9. 익스트랙션

### 9.1 핵심 선택

익스트랙션의 핵심은 메뉴에서 "탈출"을 선택하는 것이 아니라 **현재 전투력과 남은 자원, 회수품의 가치, 손실 위험을 비교해 더 진행할지 돌아올지를 결정하는 것**이다.

군도에서 복귀 가능한 방향과 안전권은 `SYS-160`이 공간적으로 표현한다.

### 9.2 정상 복귀

복귀 성공 시 기본 보존 대상:

- 회수 장비
- 잔해
- 분석 데이터

분견대에 임시 비축한 물자는 `SYS-160`이 보존 조건을 판정하고, 보존된 결과만 본 시스템의 정산 입력으로 전달한다.

### 9.3 복귀 실패

복귀 실패 시:

- 세션 중 습득한 장비는 상실
- 출격 전 장착 장비는 완전 소실보다 큰 내구도 감소 또는 일부 손상 방향
- 세션 한정 빌드 강화는 종료

출격 전 장착 장비의 정확한 손상량은 미정이다.

### 9.4 세션 중 장비 파괴와 복귀 실패의 구분

두 상황은 동일하지 않다.

#### 세션 중 장비 파괴

- 해당 장비만 사용 불가
- 소모품 기반 빌드 강화는 유지
- 세션은 계속 진행 가능

#### 복귀 실패

- 세션 자체가 실패 결과로 종료
- 세션 중 습득한 장비 상실
- 기존 장비 손상
- 세션 한정 강화 종료

이 구분을 통해 `장비 하나를 잃는 사건`과 `세션 전체를 실패하는 사건`의 손실 수준을 분리한다.

## 10. 세션 정산

### 10.1 정산 입력

세션 종료 시 정산에 들어가는 현재 소스 기반 정보는 다음과 같다.

```text
복귀 성공 / 실패
+
보존된 회수 장비
+
보존된 잔해
+
보존된 분석 데이터
+
운용 데이터
+
기존 장비 손상 상태
```

분견대 경험치와 작전 항로·전선 변화는 `SYS-160`의 책임이며, 필요 시 세션 결과를 입력으로 사용한다.

### 10.2 세션 한정 상태 초기화

세션 종료 시 다음은 다음 세션으로 그대로 이어지지 않는다.

- 세션 중 획득한 빌드 강화
- 세션 내 임시 전투 상태

반대로 복귀 성공 시 다음은 장기 상태로 이어질 수 있다.

- 보존된 회수 장비
- 잔해
- 분석 결과
- 운용 데이터
- 열화판 해금 진척

### 10.3 정산과 전선 갱신의 경계

소스 문서에서는 전선이 세션 중에는 고정되고 세션 종료 후 결과가 반영되는 구조를 사용한다.

본 문서는 세션의 성공·실패와 보존 결과를 제공하고, 실제 점령 섬·안전 항로·함대 위치의 변화는 `SYS-160`이 결정한다.

## 11. 장기 성장과 열화판

### 11.1 원본 회수 장비

원본 회수 장비는 강력할 수 있지만:

- 내구도 제한
- 수명 제한
- 반복 수리 한계

를 갖는 휘발성 자산이다.

### 11.2 해금 자원

열화판 해금에는 현재 두 종류의 누적이 사용된다.

#### 잔해 축적

동일 계통 장비 또는 관련 잔해를 반복적으로 회수한다.

#### 운용 데이터

실제 세션에서 장비를 사용한 뒤 복귀에 성공하면 운용 데이터가 축적될 수 있다.

### 11.3 열화판

`열화판`은 원본보다 낮은 성능을 가진 기본 장비다.

목적:

- 반복 플레이의 영구 보상 제공
- 실패 후 재도전 선택지 확대
- 원본 회수 장비의 파밍 가치를 완전히 제거하지 않는 범위에서 안전망 제공

원본 대비 성능 비율은 현재 확정하지 않는다.

### 11.4 전선과 열화판의 연결

소스 문서에는 전선 전진 시 적성 잔해 습득량이 증가해 제식화 난이도가 완화되는 방향이 포함되어 있다.

이 연계는 다음처럼 책임을 나눈다.

- 전선 전진과 파밍 환경 변화 → `SYS-160`
- 실제 잔해·운용 데이터 누적과 열화판 해금 → `SYS-140`

## 12. 다른 시스템과의 인터페이스

### 12.1 SYS-110 플레이어 기동

본 문서는 기동의 물리 규칙을 결정하지 않는다.

연결되는 정보:

- 기동 연동형 빌드 강화가 어떤 `기동 상태`를 조건으로 사용하는지
- 부스트가 장비·세션 자원과 연결될 경우 어떤 비용 구조를 갖는지

부스트의 최종 자원 모델은 현재 본 문서에서 확정하지 않는다.

### 12.2 SYS-120 자동 타게팅·직사 화기

본 문서가 소유:

- 어떤 장비를 장착하는가
- 장비가 어떤 공격 유형인가
- 장비가 어떤 소모품을 사용하는가
- 어떤 빌드 강화가 장비 계열에 적용되는가

`SYS-120`이 소유:

- 후보 Eligibility
- Target Selection
- Aim / Fire
- First-hit
- 직사 화기 Targeting 연출 요구

서브암 독립 Targeting형 강화는 본 문서가 강화의 존재와 획득을 소유하고, 실제 Targeting 행동은 `SYS-120`이 구현한다.

### 12.3 SYS-130 미사일 시스템

하드포인트나 유도형 장비가 Missile을 발사하는 경우:

- 장비 획득·장착·소모품·사용 횟수 → `SYS-140`
- 생성된 Missile의 FSM·Guidance·요격·유폭 → `SYS-130`

### 12.4 SYS-160 군도 작전·전방지원

`SYS-160`은 다음을 결정한다.

- 장비와 소모품이 주로 어느 공간에서 등장하는가
- 어떤 공간이 안전권인가
- 분견대 임시 비축이 보존되었는가
- 전선·작전 항로가 세션 결과에 따라 어떻게 바뀌는가

`SYS-140`은 그 결과를 입력으로 받아 장비·소모품·잔해·데이터의 최종 세션 상태를 정산한다.

### 12.5 WORLD-100

다음 내용의 설정적 이유는 `WORLD-100`이 소유한다.

- 왜 적성 회수 장비를 사용할 수 있는가
- 왜 원본 장비가 불완전 호환·수명 제한을 갖는가
- 왜 열화판 제식화가 가능한가
- 운용 데이터와 분석이 세계관에서 무엇을 의미하는가

본 문서는 해당 설정을 바탕으로 Gameplay 규칙만 소유한다.

## 13. 밸런스 원칙과 제약

### 13.1 파워 스파이크와 복귀 압박을 동시에 유지한다

빌드가 잘 풀린 세션은 강해져야 한다. 그러나 그 강함이 복귀 판단 자체를 제거해서는 안 된다.

따라서 다음 요소가 반대 방향의 압박을 만든다.

```text
빌드 강화 / 좋은 회수 장비
→ 더 깊이 갈 수 있음

소모품 감소 / 내구도 저하 / 회수품 가치 증가
→ 돌아갈 이유 증가
```

### 13.2 기본 장비는 실패 후 안전망이다

실패가 다음 세션의 플레이 자체를 막지 않도록 기본 장비를 제공한다.

기본 장비가 회수 장비보다 항상 최적 선택이 되어서는 안 되며, 회수 장비의 파밍 가치가 유지되어야 한다.

### 13.3 회수 장비는 강하지만 영구 고정되지 않는다

장비 내구도·수명·반복 수리 한계를 통해 강한 장비가 영구 고정되는 것을 방지한다.

### 13.4 손실은 강하되 재도전을 막지 않는다

현재 소스의 방향은:

- 세션 획득 장비 → 실패 시 상실
- 출격 전 장비 → 완전 삭제보다 손상

이다.

이는 익스트랙션의 손실 긴장을 유지하면서 반복 실패의 과도한 좌절을 줄이기 위한 구조다.

### 13.5 장비군은 소모품 체계를 재사용한다

모든 장비마다 별도 성장 체계를 만들지 않고 소모품 계열을 빌드 강화의 공통 기준으로 사용한다. 장비 파괴·교체 뒤에도 성장 연결을 유지하면서, 새 장비마다 강화 규칙·연결 구현·튜닝 조합을 별도로 늘리는 제작·검증 비용을 줄이는 것이 목적이다. 대신 서로 다른 소모품 계열 사이의 강화 적용 범위는 별도 판단이 필요하며 현재 Open Decision으로 남긴다.

### 13.6 강화와 Targeting의 책임을 섞지 않는다

예를 들어 `서브암이 측면 Target을 독립 공격한다`는 효과가 빌드 강화로 해금될 수 있지만:

- 강화의 획득·활성 여부 → SYS-140
- Target 후보 선택 규칙 → SYS-120

으로 나눈다.

이 원칙은 장비 문서가 Targeting 알고리즘을 다시 소유하는 것을 방지한다.

## 14. MVP와 검증

아래 항목은 Prototype 범위와 검증 질문이며 구현 완료나 확인된 결과를 뜻하지 않는다.

### 14.1 최소 세션 검증 범위

기존 제안서의 단계별 검증에서 SYS-140과 직접 관련된 최소 범위는 다음이다.

#### 전투 루프 선행 검증

- 장비 3종 후보
- 소모품 2종 후보
- 수동 장비 교체

이 단계는 장비 차이가 실제 플레이 결정을 만드는지 확인하기 위한 선행 검증이다.

#### 세션 구조 검증

포함:

- 빌드 강화
- 회수 장비
- 장비 내구도
- 정상 복귀
- 복귀 실패

후순위:

- 열화판 세부 수치
- 대규모 장비군
- 코옵에 따른 별도 정산 규칙

#### 장기 반복 검증

- 열화판 해금
- 잔해·운용 데이터 누적
- 원본 회수 장비와 열화판의 가치 차이

### 14.2 핵심 검증 질문

| 질문 | 확인하려는 것 |
|---|---|
| 소모품 기반 빌드 강화가 직관적인가 | 강화 적용 기준 이해도 |
| 장비가 파괴되어도 빌드 강화가 유지되는 구조가 납득되는가 | 손실과 성장 지속의 정합성 |
| 장비별 사거리·궤적·범위 차이가 장비 교체 이유를 만드는가 | 장비 다양성의 Gameplay 가치 |
| 빌드가 강해질수록 더 깊이 진입하고 싶은가 | 파워 스파이크와 세션 연장의 연결 |
| 소모품·내구도·회수품 가치 때문에 실제 복귀를 고민하는가 | 익스트랙션 판단 발생 여부 |
| 복귀 실패 시 손실이 긴장감을 만들되 다음 세션을 포기하게 만들지는 않는가 | 손실 강도 |
| 열화판이 원본 장비 파밍의 가치를 죽이지 않으면서 장기 보상이 되는가 | 영구 성장 강도 |

### 14.3 Prototype에서 측정할 정보

소스 문서에는 정량 임계값이 확정되어 있지 않으므로, 다음 값은 Prototype에서 비교·측정한다.

- 세션 중 장비 교체 빈도
- 소모품 고갈까지의 체감 시간
- 장비 파괴 빈도
- 강한 세션에서 심층 진입 선택 빈도
- 복귀 판단이 발생하는 시점
- 복귀 실패 후 재도전 의향
- 열화판 획득 이후 원본 회수 장비 선택 빈도

위 항목은 검증 지표 제안이며, 목표 수치는 아직 Canon이 아니다.

## 15. Open Decisions

다음 항목은 현재 확정하지 않았다.

| 영역 | 결정할 질문 | 다음 판단 조건 |
|---|---|---|
| 장착과 조작 | 최종 슬롯 수, 하드포인트 2개·4개 후보, 교체 입력 방식을 어떻게 정할지 | 장비 차이가 실제 교체 판단을 만들고 전투 중 조작이 과도한 부담이 되지 않는지 확인 |
| 소모품과 빌드 | 소모품 종류 수, 다른 계열 장비에 기존 강화를 미적용·제한 적용할지, 강화 수·단계·대가를 어떻게 정할지 | 적용 기준이 직관적이고 장비 교체 뒤에도 빌드 선택 의미가 유지되는지 확인 |
| 내구도와 수리 | 초기 내구도, 사용·피격·과출력 감소량, 임시 수리량, 최대 내구도 저하와 장비 수명을 어떻게 정할지 | 강한 장비가 순환하면서도 파괴 빈도가 세션 빌드를 과도하게 끊지 않는지 측정 |
| 익스트랙션 손실 | 기존 장비 손상량, 잔해·분석 데이터 보존 단위, 반복 실패 패널티를 어떻게 정할지 | 손실이 복귀 긴장을 만들되 실패 후 재도전을 포기하게 만들지 않는지 확인 |
| 장기 성장 | 열화판 성능 비율, 잔해 요구량, 운용 데이터 기준, 해금 단계와 기본 장비 편입 방식을 어떻게 정할지 | 열화판이 안전망이면서 원본 회수 장비의 선택·파밍 가치를 없애지 않는지 확인 |
