# SYS-160 군도 작전·전방지원 시스템

> **플레이어는 위험 해역에 먼저 진입해 적성 구획을 무력화하고 작전 항로를 개척한 뒤, 전방전술회수보급분견대를 전개해 보급·임시 비축·회수 지원을 받으며 더 깊이 진입한다. 피습과 철수 상황에서는 마지막까지 분견대와 비축 물자의 귀환을 엄호한다.**

## 0. 문서 계약

### 0.1 이 문서가 결정하는 것

본 문서는 군도를 고속 이동의 배경이 아니라 선행 강습과 구획 무력화가 전선·항로·보급·회수·철수로 이어지는 작전 공간으로 정의한다. 공간 역할, 구획 상태와 보상, 안전권·항로, 분견대·회수보급함·함재 메카의 전개·피습·철수·성장, 관련 범위와 검증 기준을 소유한다.

### 0.2 이 문서가 결정하지 않는 것

프로젝트 목표는 [PRJ-000](../00_Project/PRJ-000_프로젝트_통합기획_기준서.md)이 소유한다. Encounter 활성화·Spawn·Dormant Virtualization·Spatial은 [ARCH-100](../10_Architecture/ARCH-100_전투_적성객체_아키텍처.md), 기동·Combat/Cruise 상태는 [SYS-110](SYS-110_플레이어_기동.md), Missile 행동은 [SYS-130](SYS-130_미사일_이타노서커스.md), 장비·빌드·복귀 정산은 [SYS-140](SYS-140_세션_장비_빌드_익스트랙션.md), 설정 사실은 [WORLD-100](../30_World/WORLD-100_세계관_Canon.md)이 결정한다.

이 문서의 `구획`은 플레이어가 경험하는 작전 단위이고, `ARCH-100`의 `Zone`은 Encounter Activation·Spawn 단위다. 서로 연결될 수 있지만 같은 책임은 아니다.

### 0.3 현재 범위

예시·후보·Open Decision의 값은 확정하지 않는다. 세부 수치보다 구획·항로·지원 자산의 상태 관계와 책임 경계를 우선한다.

## 1. 시스템 요약

### 1.1 핵심 구조

```text
아군 함대권 / 점령 섬
        ↓
Cruise 진입
        ↓
군도 Encounter 탐색
        ↓
주요 적 · 적 지휘함 · 방공/초계망 교전
        ↓
구획 무력화
        ↓
작전 항로 후보 형성
        ↓
분견대 전개
        ↓
보급 / 임시 비축 / 일반 물자 회수 / 경보
        ↓
심층 작전 지속
        ↓
피습 또는 철수 판단
        ↓
분견대 귀환 / 기능 상실
        ↓
플레이어 최종 복귀
```

### 1.2 시스템이 해결하려는 문제

| 문제 | SYS-160의 해결 방향 |
|---|---|
| 넓은 바다가 단순 이동 공간으로 비는 문제 | 섬·함대·잔해·항로를 서로 다른 작전 노드로 사용 |
| 구획 전투가 일회성 처치로 끝나는 문제 | 무력화 결과를 항로·전선·지원 가능성으로 변환 |
| 파밍과 전투가 분리되는 문제 | 구획별 보상 역할을 달리하여 이동 목적과 전투 목적을 연결 |
| 익스트랙션의 복귀가 단순 버튼이 되는 문제 | 함대권·점령 섬·항로를 공간적 안전권으로 사용 |
| 전방 지원이 무조건적인 편의가 되는 문제 | 분견대를 손실 가능한 조건부 지원 자산으로 정의 |
| 아군 함대가 배경에 머무는 문제 | 분견대·회수보급함·함재 메카를 통해 아군 작전권을 Gameplay로 표현 |

## 2. 목표 플레이 경험과 디자인 원칙

### 2.1 목표 경험

#### First in, Last out

플레이어는 분견대가 진입하기 전에 먼저 위험 해역을 정리하고, 분견대가 귀환할 때에는 마지막까지 철수 경로를 엄호하는 **선도 강습 전력**으로 기능한다.

#### 전투 결과가 공간에 남는 경험

구획을 무력화하면 단순히 보상이 떨어지는 데 그치지 않고, 이후 분견대를 전개하고 작전 항로를 확장할 수 있어야 한다.

#### 더 깊이 진입할 이유와 돌아올 이유의 동시 제공

분견대의 보급·비축·회수 지원은 세션 지속력을 높이지만, 회수보급함이 손실되면 임시 비축 물자를 회수하지 못할 수 있다. 지원은 플레이어를 안전하게 만드는 것이 아니라 **더 깊이 들어갈 선택지를 늘리는 장치**로 사용한다.

#### 아군 지원이 플레이어 전투를 대체하지 않는 경험

함재 메카와 분견대는 일반 물자 회수, 소형 위협 요격, 경보, 보급, 철수 보조를 수행하되 주요 적·지휘함·보스 공략은 플레이어가 주도한다.

### 2.2 디자인 원칙

| 원칙 | 의미 |
|---|---|
| 플레이어가 먼저 길을 연다 | 분견대는 미확보 위험 해역을 대신 정리하지 않는다 |
| 닦은 구획은 실제로 달라져야 한다 | 무력화가 이후 전개·복귀·위험 구조에 영향을 준다 |
| 바다는 이동 회랑, 섬은 전투 노드 | 공간마다 역할을 명확히 구분한다 |
| 함선은 이동형 Encounter가 될 수 있다 | 대형 함선을 단순 고HP 적이 아니라 단계형 전투 공간으로 다룬다 |
| 잔해는 기회형 파밍 | 교전 직후 더 머물지 떠날지 판단하게 한다 |
| 분견대는 조건부 가방 | 편의를 주되 회수보급함 생존에 의존한다 |
| 피습은 예고된 위기 | 사전 경보 없이 비축 물자를 갑자기 잃게 하지 않는다 |
| 함재 메카는 작전권 자산 | 플레이어 상시 추종 대신 분견대 주변에서 조건부로 출격한다 |
| 성장해도 리스크는 사라지지 않는다 | 강화는 생존·경보·회수 효율을 높이되 완전 안전을 만들지 않는다 |
| RTS화하지 않는다 | 전개·철수·비축·상태 확인 중심의 최소 명령으로 제한한다 |

## 3. 군도 공간 모델

### 3.1 군도의 기본 공간 구조

군도 전장은 섬과 바다가 혼재된 고속 이동 공간이다. 플레이어는 아군 영향권에서 출격해 안전권을 벗어나 위험 해역과 심층 군도로 진입한다.

| 공간 | 기본 위험 | 주요 역할 | 대표 보상/지원 |
|---|---:|---|---|
| 아군 함대권 | 낮음 | 세션 시작·복귀 기준점 | 기본 보급, 수리, 출격 |
| 안전 항로 | 낮음~중간 | 플레이어가 인지하는 복귀 회랑 | 저등급 보급, 아군 지원 |
| 점령 섬 | 낮음~중간 | 중간 안전 노드·전선 전진점 | 정비, 보급, 제한적 장비 |
| 위험 해역 | 중간 | 일반 해상 교전·진입 경로 | 소모품, 장비 파편 |
| 섬 구획 | 중간~높음 | 지상·저고도 전투와 장비 파밍 | 회수 장비, 무기 모듈, 설계 데이터 |
| 적성 함대권 | 높음 | 이동형 해상 전투 | 고급 소모품, 파편, 분석 데이터 |
| 심층 군도 | 높음 | 하이 리스크·하이 리턴 지역 | 고등급 회수 장비, 함선 코어, 고가치 데이터 |

### 3.2 진입과 복귀의 공간적 의미

- **진입:** 아군 함대권 또는 점령 섬에서 위험 해역과 심층 군도로 이동한다.
- **복귀:** 아군 안전권 방향으로 실제 이동하여 위험권을 벗어난다.
- **세션 결과:** 장비·자원 보존 및 최종 정산은 `SYS-140`이 결정한다.
- **본 문서의 책임:** 어느 공간이 안전권 또는 복귀 경로로 기능하는지 결정한다.

### 3.3 Cruise Mode와 군도 이동

`SYS-110`의 Cruise Mode는 아직 구현·검증되지 않은 채택 방향이다. 구현되면 섬 사이 장거리 이동, 위험 해역 진입·이탈, 잔해권 탐색, 안전권 복귀에 사용하는 상위 이동 상태가 된다.

본 문서는 Cruise의 운동 수치나 FOV를 결정하지 않고 다음 **작전 정보 요구**만 제공한다.

- 전선·안전권 방향
- 자원 신호
- 큰 위험 구역
- 주요 작전 노드
- 작전 항로 또는 귀환 경로
- 특이 개체 경보

### 3.4 안전 항로와 작전 항로의 표기

현 소스에서는 `안전 항로`가 플레이어에게 보이는 복귀 회랑, `작전 항로`가 분견대 운용과 아군 작전권 편입을 설명하는 내부 개념으로 사용된다.

현행 Canon에서는 다음처럼 취급한다.

- **작전 항로:** 시스템 내부의 작전 상태와 분견대 전개 가능성을 설명하는 용어
- **안전 항로:** 플레이어에게 복귀 가능성을 직관적으로 표시하는 표현

두 용어를 완전히 동일한 상태명으로 통합할지, 서로 다른 Gameplay 상태로 분리할지는 `Open Decisions`에서 검증한다.

## 4. Encounter와 구획의 Gameplay 의미

### 4.1 SYS-160의 구획

본 문서에서 `구획`은 플레이어에게 다음을 제공하는 **작전 단위**다.

- 진입 전 위험 수준
- 주요 적과 전술 목표
- 교전 중 상태 변화
- 무력화 여부
- 보상 역할
- 이후 항로·분견대 전개 가능성

### 4.2 ARCH-100과의 경계

`ARCH-100`은 Runtime에서 Zone을 Encounter Activation/Spawn 단위로 사용한다.

SYS-160은 다음을 결정하지 않는다.

- Zone을 어떤 Broadphase로 찾는지
- 언제 실제 Entity를 생성하는지
- Dormant Encounter를 어떻게 Virtualize하는지
- SpawnSource가 어떤 ECS 구조를 사용하는지
- 적이 Zone 경계를 넘을 때 Entity를 어떻게 유지하는지

SYS-160은 대신 `ARCH-100`이 제공한 활성 Encounter가 플레이어에게 **어떤 작전 상태와 결과를 갖는지**를 정의한다.

### 4.3 일반 전투 리듬

```text
Cruise 진입
→ Combat 전환
→ 구획 전투
→ 구획 위협 감소 / 클리어
→ 감속·파밍
→ 빌드·자원 판단
→ 다음 구획 진입 또는 복귀
```

이 리듬은 군도 전장의 기본 반복 단위다.

## 5. 구획과 작전 노드 유형

### 5.1 섬 구획

- 지상·저고도 교전 중심
- 시설·방어망·적 거점과 결합 가능
- 장비 파밍의 핵심 노드
- 점령 가능한 섬은 이후 안전권 또는 전선 전진점으로 기능할 수 있음

대표 보상:

- 회수 장비
- 무기 모듈
- 설계 데이터
- 보조 소모품

### 5.2 해상 잔해권

적 함선 격파 후 형성되는 **기회형 파밍 구역**이다.

대표 보상:

- 탄약
- 연료
- 에너지 셀
- 냉각재
- 임시 수리재
- 일부 장비 파편·분석 데이터

고가치 잔해는 감속·탐색·회수 시간을 요구할 수 있으며, 이를 통해 전투 직후 **더 머물 것인가 이탈할 것인가**의 판단을 만든다.

### 5.3 적성 함대권

초계함·모함·방공 플랫폼 등의 적 함대가 형성하는 이동형 위험 영역이다.

- 바다의 공허함을 줄임
- 해상전을 전술 목표로 만듦
- 함대 격파 뒤 잔해권으로 세션 지속 자원을 제공할 수 있음

### 5.4 대형 함선 Encounter

대형 함선은 단순한 고HP Target보다 **이동형 구획**에 가깝게 취급한다.

MVP에서는 다음 정도로 축소 검증한다.

- 포탑
- 추진부
- 코어

추가 부위나 격납부·레이더 등의 세분화는 후속 범위다.

### 5.5 구획 외 해역

구획 밖도 완전히 비어 있지는 않지만, 주요 Encounter의 의미를 침해하지 않도록 저위험 적만 제한적으로 배치한다.

| 적 유형 | 구획 외 출현 | 역할 |
|---|---:|---|
| 소형 Drone | 가능 | 이동 중 긴장 유지 |
| 경초계정 | 가능 | 해상 생동감 |
| 약한 공중 위협 | 제한적 가능 | Cruise 체류 견제 |
| 중대형 함선 | 원칙적으로 제한 | 구획 목표성 유지 |
| 지휘함급 | 기본 불가 | 주요 작전 노드의 의미 유지 |
| 특이 개체 | 가능 | 명시적 예외 위협 |

### 5.6 특이 개체

`특이 개체`는 일반 구획 무력화 규칙으로 제거되지 않을 수 있는 예외적 고위험 적이다.

필수 조건:

- 일반 적과 구별되는 경보
- 레이더 또는 고정 마커
- 접근 방향 표시
- 위험도 또는 위협 성격 표시
- 분견대 영향 여부 표시 가능

특이 개체의 목적은 **안전해진 구획을 다시 무작위로 불안정하게 만드는 것**이 아니라, 규칙을 깨는 예외 위협을 플레이어가 사전에 인지하고 대응하게 하는 것이다.

## 6. 구획 상태와 무력화

### 6.1 기본 상태

| 상태 | 의미 | Gameplay 효과 |
|---|---|---|
| 적성 장악 | 주요 적·지휘 노드가 살아 있음 | 고위험 전력 존재, 분견대 전개 부적합 |
| 교전 | 플레이어가 Encounter를 진행 중 | 증원·방어·주요 목표 활성 |
| 무력화 | 핵심 위협 제거 | 함대급 위협·지휘함급 적·구획 단위 증원 재출현 중지 방향 |
| 작전 항로 후보 | 무력화 구획이 아군 함대권 또는 점령 섬과 연결 | 분견대 제한 전개 가능 |
| 작전 항로 | 아군 작전권 편입 완료 | 안정적 분견대 전개·철수·보급 가능 |

### 6.2 무력화 조건

기본 무력화는 다음 요소의 조합으로 정의한다.

- 주요 적 전력 제거
- 적 지휘함 격침
- 필요 시 방공·초계망 제거

구체적인 각 Encounter의 완료 조건은 Encounter Profile에서 달라질 수 있지만, **구획 무력화는 플레이어가 해당 공간을 작전적으로 변화시켰다는 의미를 가져야 한다.**

### 6.3 무력화 효과

무력화 이후에는 적어도 다음 방향이 유지된다.

- 동일 구획의 함대급 위협 반복 재출현 억제
- 적 지휘함급 재출현 억제
- 구획 단위 증원 중지 또는 크게 축소
- 분견대 전개 가능성 증가
- 작전 항로 후보 생성 가능
- 파밍·강화·복귀 판단을 위한 일시적 여유 제공

### 6.4 재활성화

구획이 세션 중 또는 세션 간 다시 적성 상태로 돌아갈 수 있는지는 아직 확정하지 않는다.

현재 원칙:

- 세션 중 플레이어가 방금 무력화한 구획을 즉시 원상복구시키는 구조는 지양한다.
- 장기 전선 변화로 구획이 다시 위험해질 가능성은 별도 메타 규칙으로 검토한다.

## 7. 파밍 공간과 보상 역할

### 7.1 공간별 보상 역할

| 위치 | 중심 보상 | 보조 보상 | 플레이 목적 |
|---|---|---|---|
| 섬 구획 | 회수 장비, 장비 상자, 모듈, 설계 데이터 | 소량 소모품·수리 | 빌드 변화 |
| 일반 함대 잔해 | 탄약, 연료, 에너지, 냉각재, 수리재 | 파편·분석 데이터 | 세션 지속력 |
| 대형 함선 잔해 | 고급 소모품, 함선 코어, 희귀 소재 | 제한적 회수 장비 | 고위험 격파 보상 |
| 점령 섬 | 기본 보급, 정비, 저등급 장비 | 항로·전선 정보 | 중간 거점 |

### 7.2 설계 원칙

#### 섬은 장비 중심

섬에 들어가는 이유는 **현재 빌드를 바꾸거나 새로운 회수 장비를 얻기 위해서**다.

#### 함대 잔해는 소모품 중심

함대 교전은 플레이어가 현재 빌드를 더 오래 유지하며 심층으로 들어갈 수 있는 **세션 지속 자원**을 제공한다.

#### 대형 함선은 예외

대형 함선은 일반 함대보다 높은 위험을 가지므로 코어·희귀 소재·제한적 회수 장비 같은 예외 보상을 제공할 수 있다.

### 7.3 SYS-140과의 경계

본 문서는 **어디에서 어떤 종류의 보상을 얻는가**를 결정한다.

`SYS-140`은 다음을 결정한다.

- 획득한 장비의 상태
- 장비 내구도
- 소모품 보유와 사용
- 빌드 강화
- 복귀 시 보존·손실·정산

## 8. 전선과 안전권

### 8.1 안전권 구성

플레이어가 이해해야 하는 안전권은 다음 공간의 조합으로 표현한다.

- 아군 함대권
- 점령 섬
- 안전 항로 또는 작전 항로의 플레이어-facing 표현

### 8.2 전선의 공간적 표현

군도에서는 선형 육상 전선보다 **함대 위치·점령 섬·항로의 연결 상태**가 전선 역할을 한다.

| 변화 | 공간적 표현 |
|---|---|
| 전선 전진 | 점령 섬 증가, 안전/작전 항로 확장, 아군 함대 전진 배치 |
| 전선 후퇴 | 점령 섬 상실, 항로 축소, 아군 함대 후방 이동 |

### 8.3 세션 내 안정성

현재 설계 방향은 플레이어가 세션 중 판단 기준을 잃지 않도록, **세션 도중 점령 섬과 주요 안전권 상태를 과도하게 변동시키지 않는 것**이다.

전선 갱신 시점과 반복 실패에 따른 후퇴 규칙은 `Open Decisions`로 남긴다.

### 8.4 아군 지원

안전권 또는 작전권 주변에서는 다음 지원을 제공할 수 있다.

- 저등급 보급
- 방공 또는 제한적 함포 지원
- 정비
- 센서·경보

지원량은 플레이어 직접 전투를 대체하지 않는 범위에서 조정한다.

## 9. 작전 항로

### 9.1 작전 항로 후보

무력화된 구획이 아군 함대권 또는 점령 섬과 연결되면 `작전 항로 후보`가 될 수 있다.

기본 의미:

- 플레이어가 사전에 길을 열었다.
- 분견대가 진입할 최소 조건이 충족됐다.
- 아직 완전히 안정적인 아군 작전권이라고 보장하지는 않는다.

### 9.2 작전 항로

작전 항로는 아군 작전권에 편입되어 분견대가 보다 안정적으로 이동·전개·철수할 수 있는 회랑이다.

작전 항로의 가치:

- 분견대 전개 지점 제공
- 보급·비축·회수의 전방 확장
- 플레이어 복귀 방향의 직관화
- 전투 결과를 공간적 진척으로 변환

### 9.3 항로 형성의 핵심 원칙

- 플레이어의 선행 강습 없이 분견대가 먼저 위험 해역을 점유하지 않는다.
- 항로는 전투 결과를 보상으로 환산하는 시스템이지 단순 UI 선이 아니다.
- 항로가 확보돼도 특이 개체나 피습 이벤트까지 제거되는 것은 아니다.

## 10. 전방전술회수보급분견대

### 10.1 역할

`전방전술회수보급분견대`는 플레이어가 확보한 해역에 후속 전개되는 **전방 회수·비축·보급·경보 자산**이다.

| 기능 | 역할 |
|---|---|
| 전진 보급 | 탄약·연료·에너지 등 세션 지속 자원 보조 |
| 임시 비축 | 일반 파밍 물자를 조건부로 맡김 |
| 전술 회수 거점 | 함재 메카가 회수한 일반 물자를 집적 |
| 경보 중계 | 적 접근·피습·분견대 상태 전달 |
| 철수 대상 | 위험 시 본 함대로 귀환 |
| 성장 자산 | 경험치로 생존성·센서·회수 효율 개선 |
| 리스크 자산 | 작전 지속능력 상실 시 임시 비축 회수 실패 가능 |

### 10.2 전개 조건

| 공간 상태 | 기본 전개 판단 |
|---|---|
| 적성 장악 구획 | 전개 불가 또는 비권장 |
| 교전 구획 | 기본 전개 불가 |
| 무력화 구획 | 제한적 전개 가능 |
| 작전 항로 후보 | 전개 가능 |
| 작전 항로 | 안정적 전개 가능 |
| 본 함대권 인접 | 안정적 전개 가능 |

구체적인 거리·연결 조건은 아직 확정하지 않는다.

### 10.3 플레이어 명령 범위

MVP의 명령은 최소화한다.

| 명령 | 의미 | MVP |
|---|---|---:|
| 전개 요청 | 확보된 해역에 분견대 배치 | 포함 |
| 철수 요청 | 본 함대로 귀환 시작 | 포함 |
| 임시 비축 | 일반 물자 맡김 | 포함 |
| 상태 확인 | HP·회수보급함·비축 가치 확인 | 포함 |
| 보급 요청 | 일정 범위 내 보급 | 후순위 또는 제한적 포함 |

세부 함선별 이동·공격 지시를 제공하지 않는다.

### 10.4 First in, Last out와의 관계

```text
Player First In
→ Route Clearing
→ Detachment Deployment
→ Sustainment
→ Crisis Response
→ Detachment Withdrawal
→ Player Last Out
```

분견대는 플레이어보다 먼저 위험 해역을 해결하는 전력이 아니라, **플레이어가 만든 작전 기회를 확장하는 후속 자산**이다.

## 11. 회수보급함과 임시 비축

### 11.1 회수보급함의 역할

`전방전술회수보급함`은 분견대의 보급·수납·정비·회수 기능을 묶는 **루트 노드**다.

현재 기본 판정:

- 회수보급함이 생존하면 분견대의 핵심 비축·보급 기능을 유지한다.
- 회수보급함이 침몰하거나 전투 지속 불능이 되면 분견대의 작전 지속능력 상실로 취급할 수 있다.
- 다른 호위 전력이 남아 있더라도 회수보급함 기능 상실은 임시 비축 시스템에 직접 영향을 준다.

### 11.2 임시 비축의 목적

임시 비축은 인벤토리 확장이 아니라 **조건부 안전화 장치**다.

플레이어는 일부 일반 자원을 분견대에 맡겨 자신의 즉시 손실 위험을 줄일 수 있지만, 분견대가 귀환하기 전에 회수보급함을 잃으면 해당 비축 물자를 회수하지 못할 수 있다.

### 11.3 비축 대상

| 기본 비축 가능 | 기본 비축 제한 |
|---|---|
| 일반 소모품 | 회수 장비 |
| 일반 잔해 | 희귀 장비 |
| 임시 수리재 | 고가치 설계 데이터 |
| 일반 파밍 물자 | 보스 코어·핵심 선택 보상 |

구체적인 분류는 `SYS-140`의 Item/Equipment 모델과 연동해 확정한다.

### 11.4 보존과 실패

공간·지원 측 판정은 본 문서가 소유한다.

- 분견대 본 함대 복귀 성공
- 회수보급함 생존
- 분견대 작전 지속능력 유지 여부

최종적으로 어떤 자원이 세션 정산에 보존되는지는 `SYS-140`이 소유한다.

### 11.5 회수보급함 강화의 의미

강화는 주로 다음 경험으로 연결한다.

- 생존 시간 증가
- 피습 조기 탐지
- 철수 성공 여유 증가
- 비축 처리량 또는 용량 증가
- 손상 후 기능 유지 가능성 증가

## 12. 함재 메카 전술지원

### 12.1 기본 역할

함재 메카는 플레이어와 같은 계열의 메카닉을 사용하는 아군 작전 자산이다.

핵심 역할:

- 소형 위협 요격
- 회수보급함 방어
- 일반 물자·잔해 회수
- 물자 운반
- 분견대 작전권 시각화
- 철수 엄호

함재 메카가 주요 적·지휘함·보스를 대신 해결하지 않도록 제한한다.

### 12.2 상태 모델

| 상태 | 조건 | 행동 |
|---|---|---|
| 모함 대기 | 전투 없음 | 본 함대 또는 분견대 격납 |
| 분견대 초계 | 분견대 전개 | 작전권 주변 순찰 |
| 위협 탐지 | 적 접근 | 경보 전달·요격 준비 |
| 근접 전술지원 | 플레이어가 작전권 내 교전 | 소형 적·미사일 요격, 제한 지원 |
| 물품 회수 | 전투 종료 또는 드랍 발생 | 일반 소모품·잔해 회수 |
| 수송 | 물자 적재 완료 | 회수보급함으로 운반 |
| 분견대 방어 | 피습 또는 회수보급함 위험 | 접근 위협 우선 요격 |
| 철수 엄호 | 분견대 귀환 | 추격 위협 견제 |
| 귀환·재정비 | 임무 종료 또는 손상 | 모함 복귀·쿨다운 |

### 12.3 전투 우선순위

기본 우선순위:

1. 분견대에 접근하는 Missile·Drone·소형기
2. 회수보급함 직접 위협
3. 플레이어 주변 저위험 적
4. 드랍된 일반 소모품·잔해
5. 중대형 적은 직접 격파보다 견제

Missile 자체의 Targetable 조건과 요격 가능한 내부 상태는 `SYS-130`, Targeting 인프라는 `ARCH-100` 및 관련 Targeting 규칙을 따른다.

### 12.4 회수 역할 제한

함재 메카는 일반 파밍 피로를 줄이는 보조 자산이다.

- 일반 소모품·잔해 회수: 권장
- 회수 장비 자동 획득: 제한
- 희귀 설계 데이터·보스 코어 자동 획득: 기본 비권장

고가치 보상은 플레이어의 직접 선택과 위험 감수를 보존한다.

### 12.5 연출 원칙

- 플레이어 주변 상시 선회는 피한다.
- 분견대 주변에서 저빈도로 초계한다.
- 필요 시 고속 진입해 지원이 도착했다는 느낌을 준다.
- Missile 요격과 물자 회수 후 귀환 항적을 주요 시각 피드백으로 활용한다.
- 위기 시 편대 긴급 출격은 강한 연출로 제한적으로 사용한다.
- 반복 플레이를 방해하는 컷신성 연출은 지양한다.

## 13. 분견대 피습 이벤트

### 13.1 일반 교전과의 분리

피습 이벤트는 분견대 주변의 모든 소규모 교전을 의미하지 않는다.

- 일반 잡몹 접근: 배경 위협
- 중규모 이상 조직적 공격: 피습 이벤트
- 구획 규칙을 깨는 고위험 접촉체: 특이 개체 또는 별도 이벤트

이를 분리하여 피습이 지나치게 자주 발생하는 것을 막는다.

### 13.2 피습 위험에 영향을 줄 수 있는 요소

현재 검토 후보:

- 작전 심도
- 임시 비축 물자의 가치
- 주변 해역의 섬멸·무력화 정도
- 특이 개체 존재
- 분견대 체류 시간

정확한 확률식은 확정하지 않는다.

### 13.3 예고 원칙

피습으로 중요한 손실이 발생할 수 있다면 플레이어에게 먼저 대응 기회를 줘야 한다.

필수 정보 후보:

- 적 접근 방향
- 적 접근 거리
- 예상 도달 시간
- 위협 등급
- 현재 회수보급함 상태
- 비축 물자 가치
- 철수 권고 여부

### 13.4 대응 선택

플레이어는 상황에 따라 다음을 선택할 수 있다.

- 구원하러 복귀
- 분견대 철수 요청
- 심층 작전 지속
- 피습 위험을 감수

피습은 플레이어를 자동으로 되돌리는 강제 이벤트가 아니라 **현재 심층 작전의 가치와 이미 확보한 자산의 가치를 비교하게 하는 선택**이어야 한다.

## 14. 경보와 철수

### 14.1 철수는 즉시 안전이 아니다

철수 요청은 분견대의 귀환 상태를 시작할 뿐 즉시 손실 위험을 제거하지 않는다.

귀환 완료 전까지:

- 잔존 적의 추격
- 피습 세력
- 특이 개체
- 회수보급함 손상

등의 위험이 남을 수 있다.

### 14.2 자동 철수 후보 조건

| 조건 | 기본 처리 |
|---|---|
| 분견대 HP가 위험 수준 | 자동 귀환 후보 |
| 회수보급함 HP가 위험 수준 | 강한 철수 권고 또는 자동 귀환 후보 |
| 함재 메카 손실률 과다 | 철수 판단에 반영 |
| 주변 위협도 한계 초과 | 철수 판단에 반영 |
| 플레이어와 지나치게 멂 | 구원 가능성에 반영 |

정확한 임계치는 미확정이다.

### 14.3 Last out 엄호

분견대 철수 중 플레이어가 귀환 경로의 위협을 제거하면 `Last out` 경험이 성립한다.

이때 플레이어의 역할은 분견대를 직접 RTS 방식으로 호위하는 것이 아니라:

- 추격 위협 제거
- 특이 개체 차단
- Missile/Drone 밀도 감소
- 회수보급함에 접근하는 위험 우선 제거

등으로 표현한다.

### 14.4 경보 UI 원칙

UI는 명령판보다 **상태 이해와 손실 예방**에 집중한다.

평상시:

- 분견대 상태 축약 표시
- 회수보급함 상태
- 비축 가치

위기 시:

- 위협 방향
- 접근 시간
- 위험 등급
- 철수 가능 여부
- 분견대 기능 상실 위험

을 확장 표시한다.

## 15. 분견대·함재 메카 성장과 손상

### 15.1 성장 방향

분견대와 함재 메카는 실제 운용과 생존을 통해 `작전 경험치`를 얻을 수 있다.

성장은 **함급이나 기종 자체의 진화가 아니라 같은 자산의 장비·방호·센서·숙련 향상**으로 해석한다.

| 대상 | 허용 성장 방향 | 기본 비채택 방향 |
|---|---|---|
| 회수보급함 | 장갑, 손상통제, 보급 처리량, 비축 용량, 센서 | 함급 자체 변화 |
| 호위함 | 방공, 요격, 전자전, 방호 | 구축함→순양함식 자동 변화 |
| 함재 메카 | 무장 모듈, 장갑, 추진기, 회수 모듈, 센서, AI 숙련 | 다른 기종으로 자동 진화 |
| 분견대 전체 | 대응 속도, 철수 효율, 경보 정확도, 작전권 유지력 | 자동 대형 함대화 |

### 15.2 경험치 획득 행위

대표 후보:

- 임시 비축 물자 귀환 성공
- 피습 이벤트 생존
- 철수 중 회수보급함 생존
- 함재 메카 일반 물자 회수
- Missile·Drone 요격
- 작전권 내 플레이어 지원
- 특이 개체 위협에서 생존
- 손상된 회수보급함의 생환

### 15.3 성장 원칙

- 주요 적 처리 능력이 플레이어를 대체할 정도로 증가하지 않는다.
- 강화 후에도 회수보급함 손실 가능성은 남긴다.
- 자동 회수는 일반 물자 중심으로 유지한다.
- 강화 선택은 전개·철수·경보·비축과 같은 작전 운영 능력에 집중한다.

### 15.4 손상과 일시 운용 불능

MVP에서는 영구 손실보다 **손상·수리·일시적 성능 저하**를 우선 검증한다.

| 상황 | 기본 방향 |
|---|---|
| 함재 메카 격파 | 일정 시간 또는 다음 세션 일부 구간 출격 불가 후보 |
| 회수보급함 대파 | 다음 세션 비축/보급 성능 일시 저하 후보 |
| 호위함 손상 | 피습 대응력 저하 |
| 분견대 철수 실패 | 임시 비축 물자 회수 실패 |
| 반복 운용 성공 | 경험치·숙련 상승 |

함선·함재 메카의 영구 손실은 MVP 기본안이 아니다.

## 16. 세션·장비 시스템과의 연결

### 16.1 세션 중 연결

SYS-160은 세션에서 **공간적 선택과 전방 지원 상태**를 제공한다.

```text
전투 구획 진입
→ 파밍
→ 분견대 전개 또는 기존 분견대 활용
→ 일반 물자 일부 임시 비축
→ 보급으로 세션 지속력 회복
→ 심층 진입
→ 피습/철수/복귀 판단
```

### 16.2 SYS-140과의 책임 경계

SYS-160:

- 안전권·작전 항로가 어디에 있는가
- 분견대에 맡길 수 있는 조건이 있는가
- 회수보급함이 생존했는가
- 분견대가 귀환에 성공했는가

SYS-140:

- 어떤 Item이 비축 가능한가의 최종 Item Type 계약
- 장비·소모품의 실제 보유 상태
- 세션 종료 시 보존·손실
- 장비 내구도·수리·빌드 강화 정산

### 16.3 플레이어 복귀와 전선 결과

플레이어의 최종 장비·자원 정산은 SYS-140이 결정한다.

본 문서는 전선 결과가 이후 공간 상태에 반영될 수 있도록 다음 정보를 제공한다.

- 무력화된 구획
- 확보된 작전 항로
- 점령 섬 상태
- 분견대 생존·철수 결과
- 작전 경험치 발생 근거

정확한 메타 갱신 시점은 Open Decision이다.

## 17. 성능·범위·밸런스 제약

### 17.1 Runtime 성능 경계

SYS-160은 필요한 작전 동작과 반응성을 요구하고, 구체 Runtime은 `ARCH-100`에 위임한다.

| 비용 원인 | 시스템 요구 | 줄이려는 비용 | 대가·검증점 |
|---|---|---|---|
| 먼 군도 전체의 Encounter | 비활성 Encounter는 실제 적 Entity를 상시 유지하지 않음 | 비상호작용 구획의 Simulation 비용 | Cruise 접근 전에 필요한 Encounter가 준비되는지 확인 |
| 분견대·함재 메카·구획 표현 증가 | MVP의 동시 운용 수와 편대 규모를 제한 | 활성 객체·표현·지원 판단의 증가 | 지원 존재감과 작전 규모가 충분한지 확인 |
| Cruise 고속 이동 | 접근 중인 Encounter를 미리 준비할 수 있어야 함 | 진입 순간 Spawn·Asset 준비 spike | Prewarm·Activation 방식은 `ARCH-100` 책임 |
| 피습 대상 탐색 | 전체 월드 반복 검색 대신 Scheduling·Spatial 후보 사용 | 저빈도 이벤트를 위한 전수 검색 | 경보와 대응 시간이 늦어지지 않는지 확인 |

### 17.2 범위 제약

핵심 작전 가설을 먼저 검증하고 구현·UI·콘텐츠·튜닝 조합이 함께 늘어나는 것을 막기 위해 MVP에서 다음 확장을 제한한다.

- 다수 분견대 동시 운용
- 함선별 세부 지시 UI
- 복잡한 함대 편성 시스템
- 대규모 함재 메카 편대
- 정교한 연쇄 피습 이벤트
- 영구 함선/함재 메카 손실
- 복잡한 분견대 성장 트리

### 17.3 밸런스 불변조건

- 분견대가 플레이어의 주요 전투를 대신하지 않는다.
- 조건부 가방이 무조건 안전한 저장소가 되지 않는다.
- 피습은 사전에 인지 가능해야 한다.
- 플레이어가 무력화한 구획의 변화가 실제로 체감돼야 한다.
- 특이 개체는 예외임을 명확히 표시한다.
- 함재 메카는 상시 화면을 점유하지 않는다.
- 철수는 즉시 안전화가 아니다.
- 성장 후에도 손실 가능성은 남긴다.

## 18. MVP와 검증

아래 단계와 질문은 검증 계획이며 구현 완료나 확인된 결과를 뜻하지 않는다.

### 18.1 최소 구현 범위

권장 MVP 순서는 구현 강제가 아니라 **검증 의존성 순서**다.

| 단계 | 검증 대상 | 최소 기능 |
|---:|---|---|
| 1 | 구획 결과가 공간 변화를 만드는가 | 구획 상태, 적 지휘함, 무력화 판정 |
| 2 | 작전 항로가 이해되는가 | 무력화→항로 후보→전개 가능성 |
| 3 | 분견대가 세션 지속력을 높이는가 | 분견대 1개 전개·상태 표시 |
| 4 | 조건부 가방이 의미 있는가 | 회수보급함, 임시 비축, 기능 상실 시 회수 실패 |
| 5 | 손실이 억까로 느껴지지 않는가 | 접근 경보, 위협 방향, 철수 요청 |
| 6 | 철수가 별도 판단을 만드는가 | 자동/수동 귀환, 귀환 중 위험 |
| 7 | 함재 메카가 보조 자산으로 읽히는가 | 초계→요격/회수→귀환 최소 FSM |
| 8 | 성장 루프가 작전 운영을 강화하는가 | 기본 경험치 + 센서/비축 등 1~2개 강화 |

### 18.2 핵심 검증 질문

#### 공간과 전투

- 섬·함대·잔해권의 역할 차이를 플레이어가 구분하는가?
- 구획 무력화가 단순 전투 완료가 아니라 작전 공간의 변화로 느껴지는가?
- 바다 이동이 지나치게 비거나 단조롭지 않은가?
- Cruise 이동과 Encounter 밀도가 서로 방해하지 않는가?

#### 항로와 분견대

- 작전 항로 후보와 작전 항로의 차이를 이해할 수 있는가?
- 분견대 전개가 플레이어가 직접 만든 성과처럼 느껴지는가?
- 임시 비축이 편리하지만 무조건 안전한 가방처럼 느껴지지 않는가?
- 분견대 관리가 액션 흐름을 끊는 RTS 조작으로 변하지 않는가?

#### 피습과 철수

- 경보 후 대응할 시간이 충분한가?
- 구원·철수·심층 지속의 선택이 실제로 고민되는가?
- Last out 엄호가 반복 작업이 아니라 작전 마무리 경험으로 느껴지는가?

#### 함재 메카

- 함재 메카가 플레이어 전투를 대체하지 않으면서도 존재 가치가 있는가?
- 일반 물자 회수가 파밍 피로를 줄이는가?
- 조건부 출격이 상시 동행보다 연출적 가치가 높은가?

#### 성장

- 센서·방공·비축·손상통제 등의 강화가 분견대 운용 개선으로 체감되는가?
- 성장 후에도 회수보급함 손실 가능성이 충분히 남는가?

## 19. Open Decisions

다음 항목은 방향만 채택했거나 미정이며, 임의로 Canon 값으로 확정하지 않는다.

| 영역 | 결정할 질문 | 현재 범위·다음 판단 조건 |
|---|---|---|
| 항로 상태 | 안전 항로와 작전 항로를 통합할지, 분견대 전개 거리를 어떻게 정할지 | UI 이해도와 상태 수, 본 함대·점령 섬 연결과 세션 길이를 함께 확인 |
| 군도 지속·콘텐츠 | 구획 재활성화, 절차 생성, 전장 밀도, 전선 갱신·후퇴, 대형 함선 부위 구성을 어떻게 정할지 | 성취 보존·실패 강도·이동 피로·전투 빈도·제작 공수를 비교한다. 대형 함선은 MVP에서 포탑·추진부·코어 3요소 후보로 검증 |
| 분견대 운용 | 동시 운용 수, 임시 비축 용량, 보급 요청 규칙을 어떻게 정할지 | MVP는 1개 분견대를 기준으로 관리 복잡도, 조건부 가방의 가치·손실 위험, 보급 남용 가능성을 확인 |
